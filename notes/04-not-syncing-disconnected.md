# Outlook shows Disconnected, Trying to connect, or not syncing
keywords: disconnected, trying to connect, not syncing, offline, working offline, no new mail, not receiving, sync, send receive

## Questions
- Does the status bar say Disconnected, Trying to connect, or Working Offline? [yes]
- Does the user have internet, and does Outlook on the web work? [yes]
- Is the Send/Receive tab showing "Work Offline" turned on? [yes]

## Warnings
- If Outlook on the web does not work either, it is a network or account issue, not Outlook.
- Check the simple things first: internet, VPN, and the Work Offline button.

## Steps
1. Check the user has internet, and that Outlook on the web loads.
2. In Outlook, open the Send/Receive tab and make sure "Work Offline" is NOT highlighted.
3. Close and reopen Outlook.
4. Run Send/Receive All Folders (F9).
5. If it is still disconnected, restart the PC and try again.
6. If still stuck, create a new profile (see the profile fix note).
